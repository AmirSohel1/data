🎤 SYNCHRONIZED SPOKEN VOICEOVER SCRIPT (READ ALOUD DURING THIS SLIDE):
Building a distributed platform like AeroBook involves resolving real distributed systems challenges. Here are three key innovations we engineered into the platform:

1. High-Concurrency Seat Locking & Anti-Overselling: To prevent race conditions when multiple users book the last available seat simultaneously, our Flight Service implements pessimistic row-level locking using SELECT FOR UPDATE within an isolated transactional boundary. This completely eliminates seat overselling. 2. Hybrid Eventual Consistency with RabbitMQ: Instead of slow, fragile distributed two-phase commits, we leverage RabbitMQ AMQP messaging. When a payment succeeds, the booking service asynchronously publishes seat deduction and e-ticket generation events, keeping microservice response times under 50 milliseconds. 3. Perimeter Authentication with Zero Internal Overhead: The Netty API Gateway decrypts and verifies JWT tokens at the boundary, and mutates downstream request headers with trusted identity claims (X-User-Id and X-User-Role). Downstream microservices evaluate roles instantly without repeated asymmetric cryptographic decodes.
